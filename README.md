# 📘 ML_101: A Beginner-Friendly Machine Learning Journey  

Welcome to **ML_101** — a self-made, open-source course designed to share my learning journey in **Machine Learning** with a community of curious learners.  
The purpose of this project is simple: **to learn and grow together.**  

---

## ✨ Philosophy  
This course is not about *copy-pasting pre-built models*.  
Instead, we go step by step, building concepts and code **from scratch**.  
The goal is to understand:  
- the **math behind ML models**,  
- the **reasoning behind each step**, and  
- the **mechanisms** that make algorithms work.  

I believe that true learning comes when you know *why* a model works, not just that it does.

## 💻 How to Use  
- All notebooks are written in **Google Colab** for accessibility.  
- You can open them directly by clicking the Colab badge on top of each notebook.  
- Clone this repository if you prefer running them locally.  

```bash
git clone https://github.com/your-username/ML_101.git
cd ML_101
````

## 📚 Prerequisites

To follow along, you should be comfortable with:

* **Python programming** (NumPy, Pandas, Matplotlib)
* **Basic algorithms** and data structures
* **High-school mathematics** (linear algebra, probability, calculus basics)

No prior ML knowledge is required — we build everything step by step.
